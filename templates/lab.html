Interactive DSA Laboratory & Viva Workbench

Real-time visualization and performance analysis of all 24 data structures and algorithms implemented from scratch in pure Python. Use the tabs below to test operations, inspect memory layouts, and review syllabus-to-feature viva mappings.

No heapq / bisect No list.sort() Zero Built-in Collections
Stack Implementations dsa/stack.py

Fixed-capacity Stack, Geometric DynamicStack (resizes at 100% and 25%), and MultiStack (3 stacks in one array).

Queues & Deque Ring Buffers dsa/queue_ds.py

CircularQueue ring buffer (Recent searches) and Deque (Recently viewed products).

Binary Heap vs Linked List Priority Queue dsa/priority_queue.py

Array-based Max-Heap (O(log N) insert/extract) vs Sorted Linked List (O(N) insert, O(1) extract).

Polynomial Arithmetic & Sparse Matrix dsa/linked_list.py

Polynomial linked list addition & multiplication; User-product ratings triplet linked list.

AVL Tree (Self-Balancing BST) dsa/avl.py

Guaranteed O(log N) lookups. Tracks height balance factor and LL, RR, LR, RL rotation telemetry in real-time.

BST & Threaded BST (Stackless) dsa/bst.py

BST with recursive and explicit-stack iterative traversals; Threaded BST replaces nulls with predecessor/successor links.

B-Tree & B+ Tree (Database Indexing & Range Scans) dsa/btree.py

B-Tree of degree t=2 stores keys in all nodes; B+ Tree keeps data in leaves connected via a singly linked list for rapid range queries.

Warehouse Delivery Network (MST) dsa/graph.py: prim_mst / kruskal_mst

Weighted graph between Indian distribution centers. Compares Prim's Algorithm vs Kruskal's Algorithm (with DisjointSet cycle detection).

Graph Representations & Traversal dsa/graph.py: BFS & DFS

Adjacency List (memory efficient O(V+E)) vs Adjacency Matrix (O(1) edge test).

Sorting Algorithms Benchmark (Head-to-Head) dsa/sorting.py

Zero built-in sort. All 5 algorithms benchmarked on the 80 product catalog records.

Sort Stability Demonstrator Merge (Stable) vs Quick (Unstable)

Products pre-sorted by Price are then sorted by Rating. Notice how Merge Sort preserves price order for tied ratings while Quick Sort scrambles them!

Linear vs Binary Search Telemetry dsa/searching.py

SKU search comparison counters demonstrating O(N) linear scan vs O(log N) binary search.

Hash Table: Functions & Collision Strategies dsa/hashing.py: HashTable

Custom bucket array with zero dict storage. Switch between Division, Mid-Square, and Folding hash functions and Chaining vs Open Addressing (Linear / Quadratic probing).

Prefix Trie (Digital Search Tree) dsa/trie.py: Trie

Trie character branch paths powering search autocomplete with highlighted prefix matching.

Disjoint Set (Union-Find by Rank) dsa/disjoint_set.py

Manages product variant families and cycle detection with Path Compression and Union by Rank (near O(1) amortized).
